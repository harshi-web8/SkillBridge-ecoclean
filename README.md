🌱 EcoClean

EcoClean is a digital waste management platform that helps citizens report, track, and manage waste-related issues while promoting cleanliness awareness.

✨ Key Features

- 🔐 Login & Registration – Secure user accounts and personal dashboards.
- 🗑️ Waste Reporting – Report garbage, overflowing bins, open dumping, and other waste issues with details, location, and photo.
- 📍 Report Tracking – Each complaint gets a reference ID and can be tracked through:
  Submitted → Under Review → In Progress → Resolved
- 🔔 Status Updates – Users can see updates on their submitted reports.
- 📢 Awareness – Tips and information about waste segregation, recycling, composting, and proper disposal.
- 📊 Dashboard – View submitted, pending, and resolved reports.
- ⚠️ Limitations – Resolution depends on the responsible waste-management team; accurate reporting and internet access are required.

🌍 Goal

To make waste reporting simple and transparent, encourage responsible waste disposal, and create greater awareness for cleaner communities.

EcoClean — Report. Track. Act. Keep It Clean.
